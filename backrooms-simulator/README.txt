cna-backrooms, browser build (WebAssembly + WebGL 2 via CNA).
Serve this directory with any static web server that sends .wasm as application/wasm, e.g.
    python3 -m http.server 8080
and open http://localhost:8080/ . Click the picture to capture the mouse; Esc releases it.
Options of the desktop program can be passed in the address: ?arg=--seed&arg=31337
